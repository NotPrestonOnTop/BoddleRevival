# Boddle Revival

A self-hosted private server for the Boddle math game, built to keep up with
**the latest client**. Boddle updates often and its server API is not public, so this
project doesn't hard-code a guessed protocol. It **learns the protocol from the client
you play**:

1. **Capture**: play the current version with your own account and save the network traffic (a `.har` file).
2. **Replay**: import the capture. The server immediately answers the client with the recorded responses.
3. **Replace**: turn recorded endpoints into real handlers backed by this server's own accounts, coins, shop, progress and question generator, one endpoint at a time.

When Boddle ships a new version, capture again. New or changed endpoints show up in
`npm run analyze` and on the admin dashboard's **Unhandled requests** list.

> Status: the server, tooling and native game backend work and are tested. The mapping
> of Boddle's real endpoints onto that backend still has to be built from your
> captures (step 3). See [docs/ROADMAP.md](docs/ROADMAP.md).

## Quick start

Requires Node.js 20+ and no npm dependencies.

```bash
npm start              # http://localhost:8080, admin at http://localhost:8080/admin
npm test
```

Optional: copy `config.example.json` to `config.json` to change ports, enable HTTPS, etc.

## Workflow

```bash
# 1. Record a play session (see docs/CAPTURING.md), then:
npm run import-har -- ~/Downloads/boddle-session.har --host boddle
# 2. See what the client talks to:
npm run analyze
# 3. Generate editable handler stubs for endpoints you want to make "real":
npm run scaffold -- --match "login|student|profile"
# 4. Point the client at your server (docs/CONNECTING.md) and play.
#    Anything still missing appears under "Unhandled requests" in /admin.
```

Request handling order: **custom handlers** (`src/routes/custom/`) → **native API**
(`/api/v1/*`) → **static client files** (optional) → **recorded replay** → 404 (logged).

## What's inside

| Path | What it does |
| --- | --- |
| `src/server.js` | HTTP/HTTPS server, dispatch, CORS, unhandled-request log |
| `src/routes/api.js` | Native game API: accounts, questions, rewards, shop, avatar, progress, leaderboard |
| `src/routes/custom/` | Your handlers for the real client's endpoints (see `_example.js`) |
| `src/game/questions.js` | Original K–8 math question generator (11 skills) |
| `src/game/economy.js` | Coins, XP, levels, streaks, shop catalog |
| `src/captures.js`, `src/har.js` | Capture import, secret scrubbing, path normalization, replay matching |
| `src/admin.js` | `/admin` dashboard: players, recorded endpoints, unhandled requests, coin grants |
| `tools/` | `import-har`, `analyze`, `scaffold` CLIs |

### Native API (`/api/v1`)

| Method | Path | Notes |
| --- | --- | --- |
| POST | `/auth/register` | `{username, password, displayName?, grade?}` → `{token, player}` |
| POST | `/auth/login` | `{username, password}` → `{token, player}` |
| POST | `/auth/logout` | |
| GET/PATCH | `/me` | profile; PATCH `{displayName?, grade?}` |
| PUT | `/me/avatar` | `{hat: "hat-beanie", ...}` (must own items) |
| GET | `/skills` | available question skills |
| GET | `/questions/next?skill=&grade=` | question without its answer |
| POST | `/questions/:id/answer` | `{answer}` or `{choiceIndex}` → result, coins/XP earned |
| GET | `/shop`, POST `/shop/buy` | `{itemId}` |
| GET | `/progress`, POST `/progress/:levelId` | `{stars: 0-3}` |
| GET | `/leaderboard` | top 50 by XP |
| GET | `/health` | |

Authenticated calls send `Authorization: Bearer <token>`.

## Ground rules

This is a fan project for personal and educational use. It is not affiliated with
Boddle Learning.

- **Don't commit Boddle's files.** The game client, art, audio and question content
  belong to Boddle. `client/`, `captures/`, `*.har` and `data/` are git-ignored for
  that reason. Handlers generated by `npm run scaffold` embed recorded responses, so
  check them before you push.
- **Don't collect real Boddle logins.** Players on your server make *new* accounts
  here. Never host a page that asks people, especially students, for their real
  Boddle credentials.
- **Keep it private.** It's a private server for you and people you know, not a
  public replacement for the official service.
